# ARM Linked Performance Monitor — Mobile v3.1

A standalone PWA with four linked marine engine performance charts. No vessel name is shown.

## GitHub Pages

Upload **the contents of this folder**, not the parent folder or ZIP, to the root of a new GitHub repository. All files are flat in one folder, to simplify uploads from an iPhone.

In repository Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save.

The URL will be https://USERNAME.github.io/REPOSITORY/

Open in Safari on iPhone → Share → Add to Home Screen. The service worker caches app resources after the first successful online visit.

## Caution

Curves are approximate digitizations from photographs. Confirm engine MCR and curve definitions before operational use. No uploaded data is needed. Browser history is local.
